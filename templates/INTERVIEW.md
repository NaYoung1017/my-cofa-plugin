# INTERVIEW — 담당자 질문과 답

> 질문은 사용자가 골라 직접 보낸다. 답을 받으면 그대로 붙여넣고 기록한다.
> 질문 수는 목표가 아니다. 답이 요구·설계를 바꿨는지가 중요하다.

## 질문 후보 (영향도 순, 아직 안 보낸 것 전부)

| # | 질문 | 연결 항목 (U-n / I-n / R-n) | 영향도 | 답에 따라 무엇이 바뀌나 | 상태 |
|---|---|---|---|---|---|
| | | | | | 대기 |

상태: 대기 / 이번에 보냄 / 보냄 → Q-n / 안 묻기로 함(BRIEF 처리 칸에 이유)
