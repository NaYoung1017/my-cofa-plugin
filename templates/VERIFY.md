# VERIFY — 검증 기록

> 실제로 실행한 것만 PASS/FAIL. 실행하지 않았으면 NOT_RUN. 검사 대상 0건은 PASS가 아니다.

## 요구별 검증

| ID | 요구 | 경로 | 입력 | 기대 결과 | 실제 결과 | 판정 | 명령 / 확인자 |
|---|---|---|---|---|---|---|---|
| V-1 | R-1 | 정상 | | | | NOT_RUN | |
| V-2 | R-1 | 실패 | | | | NOT_RUN | |

경로: 정상 / 실패(잘못된 입력·빈 데이터·권한 없음) / 경계(기준값과 같은 값 등)
판정: PASS / FAIL / NOT_RUN / FAIL(한계 D-n) — 고치지 않고 제출하기로 사용자가 정한 FAIL. D-n에 그 결정을 남기고 제출 문서에도 적는다.
확인자: 명령 실행(AI) / 화면 직접 확인(사용자)
