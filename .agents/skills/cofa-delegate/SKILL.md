# cofa-delegate — 서브에이전트는 필요할 때만

메인 세션이 총괄이다. 서브에이전트는 시간을 아낄 때만 쓰고, 불필요하게 늘리지 않는다.

## 1. 만들기 전 점검
하나라도 아니면 걸린 조건을 보여주고 메인이 직접 하기를 추천하며 멈춘다. 사용자가 그 조건을 보고도 다시 만들라고 하면 `SUBAGENTS.md`에 "점검 미충족: (조건) / 사용자 이유: (말 그대로)"를 남기고 만든다. 단 "역할 둘뿐"과 "동시 2개, 세션 6회 상한"은 넘지 않는다.
- [ ] `PLAN.md`가 APPROVED 상태다 (데이터 분석 `cofa-data`는 start 단계에서도 가능)
- [ ] 맡길 일이 작업 카드 하나로 정의된다: 바꿀 파일, 완료 확인 명령, 금지 사항
- [ ] 메인이 직접 하면 10분 이상 걸리거나, 큰 데이터를 읽어 메인 맥락을 낭비하는 일이다
- [ ] 다른 진행 중인 작업과 **파일이 겹치지 않는다**
- [ ] `cofa-notes/SUBAGENTS.md`에 같은 역할이 `진행` 중이 아니다
- [ ] 동시 2개, 세션 전체 6회 상한 안이다

질문 하나, 파일 하나 읽기, 작은 수정, 결정이 필요한 일은 맡기지 않는다.

## 2. 역할 (이 둘뿐)
| 역할 | 맡는 일 | 쓸 수 있는 파일 |
|---|---|---|
| `cofa-data` | 데이터 요약·이상값·조건 위반·파일 간 불일치 찾기. 처리 방법은 선택지로만 보고 | `cofa-notes/data/` 아래 보고서만. 원본 데이터·코드는 읽기만 |
| `cofa-builder` | 승인된 작업 카드 하나 구현과 완료 확인 실행 | 작업 카드의 "바꿀 파일"만 |

## 3. 제안 (사용자 OK 필요)
아래를 보여주고 멈춘다.
```
서브에이전트 제안: cofa-builder (또는 cofa-data)
- 작업 카드: T-n (바꿀 파일 / 완료 확인 / 금지)
- 메인이 직접 하지 않는 이유: …
- 그동안 메인이 할 일: …
만들까요?
```

## 4. 생성
1. `cofa-notes/SUBAGENTS.md`에 한 줄 추가(상태 `진행`, OK 시각).
2. 등록된 커스텀 에이전트 이름(`cofa-data`, `cofa-builder`)으로 생성한다. 등록이 안 보이면 기본 서브에이전트를 만들고 `.codex/agents/<이름>.toml`의 `developer_instructions`를 프롬프트 맨 앞에 그대로 넣는다.
3. 위임 프롬프트에 다섯 가지를 모두 쓴다:
   - 목표: 이 작업이 끝나면 무엇이 되나 (요구 R-n)
   - 범위: 읽을 파일 / 바꿀 파일
   - 금지: 범위 밖 수정, 패키지 추가, 다른 에이전트 생성, 결정 확정, push
   - 완료 기준: 실행할 명령과 기대 결과
   - 보고 형식: 바꾼 파일 / 실행 명령과 실제 출력 / 사용자가 정할 것
4. 같은 역할의 이전 서브에이전트가 남아 있고 후속 지시를 보낼 수 있으면 새로 만들지 말고 그쪽에 보낸다.

## 5. 결과 받기 (메인이 한다)
1. 보고를 그대로 믿지 않는다. 완료 확인 명령을 메인이 **다시 실행**한다.
2. 바뀐 파일이 작업 카드 범위 안인지 `git diff --stat`으로 본다.
3. 사용자에게 요약: 무엇이 됐나 / 실제 결과 / 정할 것. 선택지가 있으면 사용자가 고른다.
4. `SUBAGENTS.md` 상태를 `완료`로, "메인의 확인"에 다시 실행한 결과를 적는다. 결정은 `$cofa-decide`(결정자: 사용자, 근거에 서브에이전트 보고 표시).
5. 이번 작업의 동작 원리를 사용자에게 `$cofa-build` 브리핑과 같은 형식(원리 + 예시 값)으로 짧게 설명한다. 사용자가 모르는 코드가 남지 않게 한다.

## 끝나면
- 점검에서 걸렸으면: `👉 다음 추천: 메인에서 직접 — $cofa-build T-n` (걸린 조건 한 줄, `또는: 그래도 생성 — 이유를 말해 주면 기록 후 생성`)
- 생성한 뒤: `👉 다음 추천: (그동안 메인이 할 작업) — 서브에이전트 결과가 오면 확인`
- 결과 확인 뒤: `$cofa-build T-(다음)` 또는 작업이 다 끝났으면 `$cofa-verify`
